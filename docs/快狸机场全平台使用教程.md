# 快狸机场全平台使用教程（Windows / 安卓 / iPhone）

> 本文整理自 [tanqingbo.cn](https://tanqingbo.cn/) 快狸系列教程的**配置流程部分**，覆盖 Windows、Android、iPhone 三平台的客户端安装与连接步骤。机场怎么选的方法论见本仓库 [如何挑选 Clash 机场服务](如何挑选Clash机场服务.md)，三种上网方案（机场 / 自建 VPS / 商业 VPN）的横向对比见 [科学上网完全指南](科学上网完全指南.md)。

## 快狸是什么

快狸是一款提供加密代理节点的网络加速服务（俗称「机场」），走自研客户端路线：注册账号、购买订阅后，客户端登录即可一键连接，不需要像 Clash 那样手动导入订阅链接。

**平台与协议支持（事实性信息）：**

| 项目 | 支持情况 |
|------|----------|
| 客户端平台 | Windows / macOS / Android / iOS / OpenWrt |
| 节点协议 | VMess / VLESS / Trojan / Shadowsocks |
| 多设备 | 一个账号多台设备同时在线 |
| 常见解锁目标 | Google / YouTube / Gmail / ChatGPT / OpenAI / Midjourney / Netflix / Disney+（解锁状态随节点调整变化） |

> ⚠️ 机场服务的可用性与合规性随政策环境变化，请自行评估是否使用。文中快狸官网与环球巴士链接包含作者推广码，通过链接注册/购买会为博客带来少量返利，不影响你的价格。

## 第一步（通用）：注册账号与购买订阅

三平台通用，先在电脑或手机浏览器完成：

1. 打开[快狸官网](https://iasfa.kuailitztz2.sbs/#/?code=PKv2HCjU)，点击右上角「注册」，使用邮箱和密码注册账号；

2. 快狸官网：https://iasfa.kuailitztz2.sbs/#/?code=PKv2HCjU

   ![注册页面](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/image-20260815210447250.webp)

3. 注册完进入后台，点击上方导航栏「购买订阅」，选择套餐；

   ![购买订阅页面](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/20260818112023721.webp)

4. 套餐档位（供参考，以官网实时价格为准）：

   | 档位 | 价格 | 适合 |
   |------|------|------|
   | 月付 | 15 元/月 | 短期试用、验证节点质量 |
   | 年付（轻量） | 120 元/年 | 偶尔查资料的轻度用户 |
   | 年付（大流量） | 255 元/年（100G/月） | 海外视频、AI 大模型重度用户 |

5. 购买完成后进入「仪表板」页面，滑到「客户端下载」区域，按设备类型下载对应客户端。

   ![客户端下载区域](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/image-20260901095818055.png)

## 第二步（Windows）：安装客户端并连接

1. 下载 Windows 客户端，按提示安装；
2. 打开客户端，输入注册时的邮箱和密码登录；

   ![Windows 客户端登录](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/image-20260815214226120.png)

3. 登录后可以看到订阅的节点信息，点击「快速连接」即可；

   ![点击快速连接](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/image-20260815214822150.png)

4. 连接成功后即可访问 Google、YouTube、ChatGPT 等平台。

   ![连接成功界面](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/image-20260815215001056.png)

1. 在「客户端下载」区域下载 Android 客户端，按提示安装；

## 第二步（iPhone / iPad）：外区 Apple ID + Nextin 客户端

iOS 端比其他平台多一个前提：**App Store 里下载客户端需要外区 Apple ID**（国内 Apple ID 搜索不到这类应用）。获取方式二选一：

- **直接购买**：没有外区 ID 的话，可以在[环球巴士](https://universalbus.cn/?s=wX0haoloon)上买一个，几分钟到手；
- **自行注册**（免费）：流程见 [手机科学上网教程](手机科学上网教程.md) 中的海外 Apple ID 注册章节。

准备好外区 Apple ID 后，8 步完成配置：

**步骤 1｜切换 App Store 账号**：打开 App Store，点击右上角头像 → 退出登录 → 登录外区 Apple ID。

**步骤 2｜下载 Nextin 客户端**：App Store 搜索「Nextin」，下载安装。

![App Store 搜索 Nextin](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/kuaili-ios-step2-search-nextin.webp)

**步骤 3｜导入专属识别码**：打开软件，输入识别码（见快狸后台），等待自动配置完成。

**步骤 4｜登录账号**：输入官网注册的邮箱和密码，点击登录。

**步骤 5｜一键连接**：回到首页，点击中间的连接按钮。

![点击连接按钮](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/kuaili-ios-step5-connect.webp)

**步骤 6｜允许 VPN 权限**：首次使用弹窗点击「允许」，输入手机锁屏密码。

**步骤 7｜选择节点**：点击「选择节点」入口。

**步骤 8｜更换线路**：选择一个节点（香港/日本延迟通常较低），延迟越低速度越快。

![节点列表](https://tqb4342.oss-cn-guangzhou.aliyuncs.com/img/kuaili-ios-step8-node-list.webp)

显示「已连接」后即可正常访问外网。MacBook / iMac 用户下载 macOS 客户端，流程与 Windows 一致。

## 常见问题

**登录客户端后没有节点信息？**
检查套餐是否购买成功、邮箱是否输入正确，回到仪表板确认订阅已生效；仍无节点就刷新客户端或重新登录。

**YouTube 打不开、视频加载慢？**
更换低延迟节点、切换网络（Wi-Fi/流量）测试；仍不行参考 [Clash 独立排障指南](Clash独立排障指南.md) 的排查思路。

**一个账号手机和电脑能同时用吗？**
可以，快狸一个账号支持多台设备同时在线，不用重复购买。

**快狸和 Clash 有什么区别？**
Clash 需要手动导入订阅、配置节点和分流规则，适合想精细管理的用户；快狸自研客户端登录即用、零配置，适合新手。

**iPhone 端为什么要外区 Apple ID？**
苹果对应用分发有地区限制，国内 App Store 搜索不到科学上网类应用，必须切换外区账号才能下载。

**怎么判断这个机场适不适合自己？**
先买最低档月付跑一两周，看高峰期延迟和稳定性，再决定是否续长期套餐。节点质量宣传说了不算，实测才算。
