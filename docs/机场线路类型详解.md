# Clash 机场线路类型详解：直连 / 中转 / 专线（IPLC/IEPL）的区别与选择

> 本文是 [tanqingbo.cn](https://tanqingbo.cn/) 上《[机场线路类型详解](https://tanqingbo.cn/route/)》的精选版，保留最核心的三种线路对比与选择逻辑。

机场线路分三种：直连、中转、专线（IPLC/IEPL）。它们区别的核心在于**流量从你本地到海外节点的路径怎么走**，直接决定了延迟、稳定性和抗封锁能力。

## 三种线路一眼看懂

| 特性 | 直连 | 中转 | 专线（IPLC/IEPL） |
|------|------|------|------|
| 路径 | 本地直达节点 | 经国内中转服务器再转发海外 | 运营商级国际物理专线 |
| 成本 | 低 | 中 | 高 |
| 延迟 | 高 | 中 | 低 |
| 稳定性 | 差 | 中 | 极佳 |
| 抗封锁 | 弱 | 中 | 极强 |
| 适合人群 | 新手入门 | 日常办公娱乐 | 追求极致体验 |

## 直连

请求从本地直接跳到机场节点，无中间转发。成本低、配置简单，但流量直接暴露在公网链路，容易被识别和封锁，峰值时段易丢包、高延迟。适合对速度要求不高、预算有限的用户。

## 中转

请求先经国内中转服务器，再转发到海外节点，缓解国内网络瓶颈。分普通中转和 BGP 中转（智能选路、跨运营商更好）。稳定性和速度比直连明显提升，但价格更贵、维护更复杂。适合远程办公、高清视频等进阶用户。

## 专线（IPLC / IEPL）

走运营商级国际物理链路，数据从国内直接经物理专线到海外，不经过公共网络。延迟极低、几乎不丢包、抗封锁最强，适合游戏、流媒体、金融交易等延迟敏感场景。缺点是成本高，且部分节点有超售现象。

## 怎么选

1. **新手 / 日常网页** → 便宜的直连或普通中转
2. **稳定性要求高**（远程办公、网课）→ BGP 中转
3. **延迟敏感**（游戏、流媒体、高频交易）→ 专线（IPLC/IEPL）
