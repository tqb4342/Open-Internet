# Clash 机场线路类型详解：直连 / 中转 / 专线（IPLC/IEPL）的区别与选择

> 本文是 [tanqingbo.cn](https://tanqingbo.cn/) 上《[机场线路类型详解](https://tanqingbo.cn/route/)》的完整版，讲清三种线路的网络路径、跨境原理、速度与抗封锁差异，以及不同需求该怎么选。

机场线路分三种：直连、中转、专线（IPLC/IEPL）。核心区别在于**流量从你本地到海外节点的路径怎么走**，这直接决定了延迟、稳定性和抗封锁能力。

很多机场把"专线"当营销词用，价格翻倍但体验没变。搞懂下面这些，至少能分辨你买的是什么。

## 一、三种线路一眼看懂

| 特性 | 直连 | 中转 | 专线（IPLC/IEPL） |
|------|------|------|------|
| 路径 | 本地直达节点 | 经国内中转服务器再转发海外 | 运营商级国际物理专线 |
| 成本 | 低 | 中 | 高 |
| 延迟 | 高 | 中 | 低 |
| 稳定性 | 差 | 中 | 极佳 |
| 抗封锁 | 弱 | 中 | 极强 |
| 晚高峰表现 | 明显劣化 | 有波动 | 基本无感 |
| 适合人群 | 新手入门 | 日常办公娱乐 | 追求极致体验 |

## 二、直连

**定义**：请求从本地网络直接跳到机场节点，无中间转发服务器。

**绕过防火墙的原理**：直连线路靠加密与伪装手段（Shadowsocks、V2Ray/Xray、TLS/WS 等）降低被识别概率。但因为流量直接暴露在公网链路上，仍有被识别、干扰或封锁的风险。

**优点**：成本低，很多机场默认提供；配置简单，适合新手。

**缺点**：容易被识别和封锁；网络质量极大受制于运营商和出口拥堵；峰值时段易丢包、延迟高。

**适用**：对速度要求不高、预算有限的用户。

## 三、中转

**定义**：请求先到国内中转服务器，再转发到海外节点，用一段可控的国内链路绕开最容易拥堵的公网出口段。

**两种类型**：

- **普通中转**：基于一般服务器实现，路径相对固定
- **BGP 中转**：具备智能路径选择，能根据实时网络状况动态选路，跨运营商（电信 / 联通 / 移动）中继效果明显更好

**绕过防火墙的原理**：通过"国内入口 / 中转"先承接流量再转发海外，改善跨网质量与晚高峰体验。抗干扰能力取决于入口质量、加密伪装方式和机场整体运维水平——**同样是"中转"，水平差距可以很大**。

**优点**：相较直连，稳定性和速度明显提升；一定程度规避封锁；跨网传输表现更佳。

**缺点**：成本提升，价格通常比直连贵；配置和维护较复杂，依赖机场服务方的技术能力。

**适用**：对连接质量有一定要求的进阶用户，如远程办公、高清视频。

## 四、专线（IPLC / IEPL）

**定义**：使用运营商级别的国际物理链路，数据从国内直接通过物理专线传送到海外，**不经过公共网络**。

- **IPLC**（International Private Leased Circuit）：国际私有租用线路，端到端独占
- **IEPL**（International Ethernet Private Line）：国际以太网专线，同样独占但以以太网接口交付

**绕过防火墙的原理**：走运营商级链路，区别于公网绕行，理论上更稳定、丢包更低、抗干扰更强。但要说清楚一点：**是否"完全不经过审查链路"并无绝对保证**，仍取决于运营商接入方式与落地策略。

**优点**：延迟极低、几乎不丢包；抗封锁能力最强；适合游戏、流媒体、金融交易等延迟敏感场景。

**缺点**：成本高昂，部分机场需额外购买；**有些节点存在超售现象**，高峰时段同样会掉体验——专线不等于一定不超售。

**适用**：游戏加速、高清视频、金融交易等对网络要求极高的场景。

## 五、怎么判断自己用的是哪种线路

机场未必如实标注，可以用这几个方法交叉验证：

**1. 看节点命名**

正规机场通常会在节点名里标类型，比如「香港 IEPL」「东京 BGP 中转」「美国 直连」。没标的，多半是直连或普通中转。

**2. 看延迟和抖动**

同一地区对比：专线通常延迟低且**极其稳定**（测几次几乎一个数值）；直连延迟高且波动大；中转换介于两者之间。判据是"抖不抖"，不只是"低不低"。

**3. 用 traceroute 看路径**

```
# Windows
tracert 目标IP
# macOS / Linux
traceroute 目标IP
```

- 直连：跳数多，中间会经过公网国际出口段
- 中转：会先出现国内 IP 段，再跳到海外
- 专线：跳数明显少，路径短且干净

这个方法不是绝对准确（部分节点会隐藏 ICMP），但作为辅助判断够用。

**4. 看晚高峰**

晚上 8-11 点各测一次。直连通常明显劣化，中转有波动，专线基本无感。这是最贴近真实体验的检验方式。

## 六、线路和倍率的关系

机场节点名后面常带 `x1`、`x2`、`x3` 这样的倍率，它表示**这个节点消耗流量的计费系数**。专线成本最高，所以倍率通常也最高：

- 直连：常见 `x1`，部分优质线路 `x1.5`
- 中转：`x1` 到 `x2` 居多
- 专线（IPLC/IEPL）：常见 `x2` 到 `x3`，少数更高

所以买专线前要算一笔账：同样 100G 流量，走 `x3` 的专线等于只用了 33G。**体验提升是否值这个价，取决于你的用途**——打游戏值，单纯看网页不值。

详细的倍率计算方式见 [机场倍率与流量计费完全指南](https://tanqingbo.cn/airport-rate-guide/)。

## 七、怎么选

1. **新手 / 日常网页浏览** → 便宜的直连或普通中转
2. **稳定性要求高**（远程办公、网课、视频会议）→ BGP 中转
3. **延迟敏感**（游戏、流媒体、高频交易）→ 专线（IPLC/IEPL）
4. **预算有限但想改善晚高峰** → 优先加钱上 BGP 中转，比盲目上专线划算

一个经验判断：**大多数人高估了自己对专线的需求**。如果你主要用途是看网页、查资料、偶尔看视频，一个好的 BGP 中转节点体验已经足够，省下的钱不如买更大的流量包。

## 八、常见问题

**直连线路为什么容易被封？**

流量直接走公网链路出口，特征明显，识别和干扰的成本最低。加密能降低识别概率，但改变不了"走公网"这个事实。

**BGP 中转和普通中转差别大吗？**

BGP 中转通过多路径动态选择，跨运营商效果好，晚高峰优势明显；普通中转路径固定，容易在特定链路上拥堵。跨网用户（比如联通访问电信出口的节点）感受差别尤其大。

**专线值得买吗？**

如果你追求"秒开视频、超低延迟、稳定无波动"，且主要在游戏或实时场景，专线是目前最优解。但如果只是日常浏览，溢价换来的提升你可能感知不到。

**专线一定不超售吗？**

不是。专线成本高，但超售与否取决于机场的运营策略，不取决于线路类型。判断方法还是看晚高峰的实际表现。

**为什么同一地区不同节点价格差好几倍？**

主要是线路类型（直连 / 中转 / 专线）和倍率不同。先看节点标注的线路类型，再看倍率，两者结合才知道自己付的钱买了什么。
