# Clash / Mihomo 独立排障指南（按症状排查）

> 本文是 [tanqingbo.cn](https://tanqingbo.cn/) 上《[Clash / Mihomo 独立排障指南](https://tanqingbo.cn/troubleshooting/)》的精选版，保留「按症状排查」的核心框架。

这篇文章只做一件事：**别再盲目换节点了，先按症状排查。** 很多问题看起来像"机场不行"，其实根因是下面四类之一：

- 模式不对
- 系统代理或 TUN 没接管到目标应用
- DNS 有问题
- 订阅、规则集或节点地区不适合目标服务

先记住 4 个高频结论：

1. 日常默认先用 `Rule`，`Global` 只适合临时排障
2. 浏览器能用，不代表所有 App 都能用（App/游戏/系统服务不一定跟随系统代理）
3. "能连上却打不开网页" 优先怀疑 DNS
4. AI / 流媒体问题，经常不是客户端问题，而是地区、IP 信誉或账号风控

## 八个常见症状速查

| 症状 | 优先排查 |
|------|---------|
| 显示已连接，但所有网站打不开 | 模式误开 Direct / 系统代理未开 / 系统时间不准 / DNS |
| 浏览器能开，Telegram/ChatGPT 客户端不行 | 流量没接管到 App → 开 TUN、关代理插件 |
| YouTube 能开，ChatGPT/Claude 不行 | 节点地区、共享 IP 信誉、账号风控 |
| 延迟低但速度慢 | 晚高峰、线路超售、回程质量差 |
| iPhone 可用，电脑不行 | 系统代理 / TUN 权限 / 防火墙 / 端口占用 |
| 更新订阅失败 | 订阅过期 / 官网打不开 / 客户端过旧 / 地址残缺 |
| 导订阅后没节点 | 订阅格式 / 客户端过旧 / 导错类型 |
| 游戏下载器不走代理 | TUN / UDP / 进程级代理 |

## 5 分钟最小闭环

完全不知道从哪下手时，按这 5 步重置：

1. 更新订阅
2. 切到一个已知可用节点
3. 模式设为 `Rule`
4. 开系统代理（必要时开 TUN）
5. 先测 GitHub / YouTube，再测目标服务

## 什么时候该换服务商，而不是继续折腾客户端

满足下面多条时，再考虑换服务商：多个客户端表现一致异常、多个网络环境都异常、多个地区节点都不稳、晚高峰长期不可用、官网/客服同时失联。如果只是单一服务打不开、单台设备不正常，优先排查本地配置。
