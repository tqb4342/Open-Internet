# Windows 翻墙三方案实操对比：机场 / 自建 VPS / 商业 VPN 怎么选

> 本文是 [科学上网完全指南](科学上网完全指南.md) 在 **Windows 平台** 上的落地版。三方案的全貌与横向对比见总览，本文只回答一个问题：**在你的 Windows 电脑上，到底选哪条路、分别怎么做、做完要花多少成本。**

---

## 先给结论（30 秒版）

| 你是哪种人 | 直接选这个 |
|---|---|
| 第一次翻墙，想 15 分钟用上 | 机场 + Clash 系客户端（Verge / v2rayN） |
| 有 Linux 基础，愿意折腾、想学原理 | 自建 VPS（当第二通道，别当唯一） |
| 人经常在境外、出差多、要连公共 Wi‑Fi | 商业 VPN |

一句话：**Windows 新手默认走「机场 + Clash」**，这条路教程最多、坑最少、出问题最好查。

---

## 一、三种方案在 Windows 上的真实区别

别只看"谁更安全"这种空话，落到 Windows 这一步，差别在"配置门槛"和"出问题好不好查"。

| 维度 | 机场 + Clash 客户端 | 自建 VPS | 商业 VPN |
|---|---|---|---|
| 上手步骤 | 3 步（订阅导入→选节点→开代理） | 至少十几步（买机、装内核、配证书、装客户端） | 装 App 登录即用 |
| 需要的技能 | 会复制粘贴就行 | Linux、域名、证书、防火墙 | 无 |
| 出问题排查 | 换节点 / 换模式 / 查 DNS，网上教程多 | 一切靠自己，日志定位 | 找客服 |
| Windows 上的稳定体验 | 中高（看机场线路） | 不稳（IP 被封要重搭） | 不稳（境内被墙概率高） |
| 长期成本 | 月付 10–30 元 | 年付 30–100 元，但 IP 被封有隐性成本 | 月付 30–60 元 |

> 关键认知：**自建 VPS 的"便宜"是账面上的**。IP 一旦被墙，换 IP / 重建实例的时间成本和额外支出，往往超过一年机场钱。所以自建更适合当"备援 + 学习"，而不是第一选择。

## 二、方案 A：机场 + Clash 客户端（Windows 新手首选）

### 原理一句话

机场把节点打包成一条「订阅链接」，你把它喂给 Clash 系客户端，客户端自动拉取节点、按规则分流（国内直连、国外走代理）。

### Windows 上怎么搭（三步）

1. **装客户端**：Windows 首选 [Clash Verge](https://tanqingbo.cn/clash-verge/)，或 v2rayN。都是开源免费。
2. **导入订阅**：在机场面板复制订阅链接 → 客户端点「订阅 / Profiles」→ 粘贴 → 导入。
3. **开代理选节点**：开启系统代理（或按需开 TUN），选一个低延迟节点（香港 / 新加坡 / 日本优先），浏览器访问 Google 验证。

### 三个新手最容易卡住的点

- **订阅导入后没节点**：先看订阅链接有没有复制全（多空格、少字符都会失败），再看订阅有没有过期。
- **节点测速正常但网页打不开**：八成是 DNS 没接管，切到 fake-ip 模式或检查 DNS 配置（详见 [Clash DNS 配置指南](https://tanqingbo.cn/clash-dns-guide/)）。
- **某些 App/游戏不走代理**：开 TUN 模式接管全局流量（详见 [Clash TUN 模式指南](https://tanqingbo.cn/clash-tun-mode/)）。

> 完整图文步骤见 [Windows 翻墙全流程教程](https://tanqingbo.cn/win-kuaili/)，从注册机场到连接节点每一步都有截图。

### 机场怎么选

看三点：线路稳定性（有没有独立中转/IEPL）、解锁能力（Google/ChatGPT/Netflix 是否真解锁）、客服响应。选购细则见 [如何挑选 Clash 机场服务](如何挑选Clash机场服务.md)，这里不展开。

## 三、方案 B：自建 VPS（适合技术党当备援）

### 原理一句话

买一台境外云服务器，自己装代理服务（Xray / sing-box 等），配好 TLS 伪装，再用客户端连自己的节点。

### Windows 上怎么搭（成本最高、坑最多）

1. 买一台境外 VPS（DigitalOcean / Vultr / Oracle Cloud 等）
2. 用 one-click 脚本或手装 Xray-core / sing-box
3. 申请域名 + 证书，配 TLS 伪装流量
4. Windows 装客户端，填自己的节点参数

### 两个现实提醒

- **IP 被封是常态**，不是意外。换 IP 多数平台要删实例重建，DigitalOcean 甚至不支持单独换 IP。
- **99% 的 Windows 用户不需要这一步**。除非你想学完整链路，或者需要一个"只有自己知道"的备援通道。

> 想深入，参考权威文档：[Xray-core](https://github.com/XTLS/Xray-core)、[sing-box](https://sing-box.sagernet.org/)。自建不建议第一次翻墙就上。

---

## 四、方案 C：商业 VPN（适合境外 / 出差人群）

### 原理一句话

装一个商业 App，登录即用，流量走服务商自己的服务器。

### 为什么在境内不那么推荐

- **被墙概率高**：商业 VPN 的服务器 IP 是公开的，风控很容易命中，境内连接经常时好时坏。
- **贵且不透明**：月付 30–60 元，但线路质量、日志政策都不如机场透明。

### 什么时候值得用

人在境外、连公共 Wi‑Fi 要保护隐私、或者公司配了指定 VPN。**长期在国内本地用，不推荐商业 VPN。**

## 五、一张表定夺（按你的场景）

| 场景 | 选方案 | 理由 |
|---|---|---|
| 第一次翻墙，想快速用上 | A 机场 + Clash | 门槛最低、教程最多 |
| 天天要稳定用 ChatGPT/Netflix | A 机场（挑好线路） | 稳定性最关键，别折腾自建 |
| 有 Linux 基础，想学原理 | B 自建 VPS | 当备援 + 学习，别当唯一 |
| 人在境外、出差多 | C 商业 VPN | 隐私 + 一键即用 |
| 预算极低、能接受折腾 | B 自建 VPS | 但要有 IP 被封的心理准备 |

---

## 六、安全提示（必读）

- **订阅链接就是你的账号密码**，别公开、别截图发群、别交给第三方代导入。
- 别用来路不明的"免费 VPN / 破解客户端 / 共享订阅"，隐私和账号风险极高。
- 日常开 `Rule` 分流，别把所有国内流量都走代理。
- 仅用于学习、科研、跨境办公等合法用途，请遵守所在地法律法规。
